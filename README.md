# MeuCurriculo_blazor
Aplicação web desenvolvida em Blazor com o objetivo de apresentar um currículo online de forma estruturada e interativa. O projeto utiliza componentes Razor para organizar as seções e oferece uma navegação simples entre as informações profissionais.

## Descrição

O projeto consiste em uma aplicação SPA (Single Page Application) construída com Blazor, onde o conteúdo do currículo é dividido em componentes reutilizáveis. A interface é renderizada no cliente, proporcionando uma experiência fluida sem recarregamento de página.

## Tecnologias
- .NET
- Blazor WebAssembly
- C#
- Razor Components
- HTML e CSS

## Estrutura do Projeto
A organização segue o padrão de aplicações Blazor:

MeuCurriculo_blazor
 ┣ Pages/        # Páginas principais da aplicação
 ┣ Shared/       # Componentes reutilizáveis (layout, navbar, etc.)
 ┣ wwwroot/      # Arquivos estáticos (css, imagens, scripts)
 ┣ App.razor     # Configuração de rotas
 ┗ Program.cs    # Ponto de entrada da aplicação

## Funcionalidades
Exibição de informações pessoais
Seção de habilidades técnicas
Histórico profissional
Formação acadêmica
Navegação entre seções sem recarregamento
Layout organizado em componentes

## Execução do Projeto
Pré-requisitos
.NET SDK instalado
Passos
git clone https://github.com/OlavoNicolas/MeuCurriculo_blazor.git
cd MeuCurriculo_blazor
dotnet run

A aplicação será iniciada localmente e poderá ser acessada via navegador.

Objetivo do Projeto

O principal objetivo é demonstrar o uso de Blazor na construção de interfaces web modernas utilizando C#, além de servir como base para um currículo digital extensível.
